# Agent instructions — AI Tools Assessment repo

Dit is een **operatiekit** om een productized AI assessment-dienst te testen (Corey Ganim-model), geen Normelo-product.

## Principes

- Eerst gesprekken en rapporten, daarna pas software
- Schrijf off-the-shelf tools voor; bouw geen custom apps tenzij expliciet gevraagd
- Houd deliverables dom-simpel (confused mind implements nothing)
- NL-markt: prijzen in euro, toon praktisch en direct

## Als je code toevoegt

Alleen na bewijs dat de handmatige flow werkt. Prioriteit dan:
1. Simpele landing + intake-formulier
2. Checklist/CRM voor pipeline
3. Rapport-generator (transcript → draft markdown)
