# Review call — script (30 min, fase 4)

Stuur het rapport **vóór** de call. Jij deelt scherm en loopt slide/sectie voor sectie.

## Agenda

| Min | Blok |
|---|---|
| 0–3 | Check-in: “Wat viel je op in het rapport?” |
| 3–8 | Executive summary + uren |
| 8–20 | Recommended solutions (meeste tijd) |
| 20–24 | 4-dagen plan |
| 24–27 | Major projects (upsell-zaadje, geen hard sell) |
| 27–30 | Drie closing questions |

## Per tool (formule)

1. Jouw pain was: …  
2. Tool: … kost … setup … bespaart …  
3. “Vragen hierover?”  
4. Door naar volgende  

## Tone

Arts die voorschrijft. Kalm, concreet, geen feature-dump.
