# Discovery call — script (45 min)

## Voor de call

- [ ] Intake ontvangen (bedrijfsnaam, rol, teamgrootte, huidige tools)
- [ ] Recorder klaar (Fathom/Otter)
- [ ] Vraagbank open
- [ ] Agenda: alleen discovery, geen tools

## Tijdlijn

| Min | Blok |
|---|---|
| 0–2 | Welkom, opname, verwachting |
| 2–7 | Bedrijfscontext |
| 7–20 | Dag, energie, stapels |
| 20–30 | Magic wand + kwantificeren |
| 30–40 | Team, kwaliteit, AI nu |
| 40–45 | Afronden + next step |

## Frases om klaar te hebben

- “Vertel me meer — wat gebeurt er precies stap voor stap?”
- “Hoe vaak per week? Hoe lang per keer?”
- “Wie doet dit nog meer in het team?”
- “Wat zou er gebeuren als dit proces morgen wegvalt?”

## Verboden op call 1

- Toolnamen droppen (“oh, dat is SaneBox”)
- Implementatie beloven
- Upsells pitchen
- Rapport live improviseren

## Na de call (≤15 min)

- [ ] Transcript exporteren → `clients/<klant>/transcript.md`
- [ ] 3–5 ruwe pain points noteren in eigen woorden
- [ ] Door naar `analysis/claude-prompt.md`
