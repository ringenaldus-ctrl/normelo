# AI Tools Assessment — testkit

Starterrepo om het model uit [The $1,000/hour Solo AI business](https://www.youtube.com/watch?v=dhbcVxYhWaQ) (Corey Ganim × Greg Isenberg) te testen.

**Kernidee:** 45 minuten discovery met een MKB-ondernemer → 3–7 kant-en-klare AI/SaaS-tools voorschrijven → rapport → review call. Prijs: **€999** (of start lager om te leren). Garantie: minstens **5 uur/week** terug, anders geld terug.

Dit is geen productwebsite. Dit is een **operatiekit**: scripts, prompts, templates en een pipeline om je eerste assessments te draaien.

## Mapstructuur

| Map | Inhoud |
|---|---|
| `offer/` | One-pager, garantie, ICP |
| `discovery/` | Vragenlijst + call-script (fase 1) |
| `analysis/` | Claude-prompt/skill + QA (fase 2) |
| `report/` | Rapportstructuur + voorbeeld (fase 3) |
| `review/` | Review-call + closing questions (fase 4) |
| `upsell/` | Upsell-menu + AI Concierge |
| `acquisition/` | 7 acquisitiemethodes + templates |
| `clients/` | Pipeline / tracking |
| `examples/` | Voorbeeldtranscript + output |

## Hoe je dit test (eerste 7 dagen)

1. Lees `CONCEPT.md` (15 min).
2. Kies je ICP (start smal: bijv. lokale dienstverleners, 2–20 medewerkers).
3. Doe **2 gratis mini-audits** bij mensen uit je netwerk (1 tool voorschrijven).
4. Verwerk 1 transcript door `analysis/claude-prompt.md`.
5. Vul `report/template.md` in voor die klant.
6. Doe een review-call met de 3 closing questions uit `review/`.
7. Log alles in `clients/pipeline.md`.

Pas daarna prijs omhoog (gratis → €200 → €500 → €999).

## Wat dit níet is

- Geen Normelo / EU AI Act-product
- Geen custom software bouwen in fase 1 — alleen voorschrijven
- Geen cold spam; acquisitie is lokaal, persoonlijk, of via partners

## Volgende stap (product)

Als de handmatige flow werkt (3+ betaalde assessments), kun je hier later een lichte landing + intake + rapportgenerator naast zetten. Eerst bewijs met gesprekken.
