# Uurvrij — AI Tools Assessment

Landingspagina + playbook voor het AI Tools Assessment (Corey Ganim-model).

## Site

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

De homepage biedt de dienst aan: **45 minuten Zoom discovery** → rapport → review-call.

CTA gaat nu naar `mailto:ringenaldus@gmail.com`. Vervang later door Calendly of een intake-formulier.

## Playbook

Operationele templates staan in [`playbook/`](./playbook/): discovery-vragen, Claude-prompt, rapporttemplate, upsells, acquisitie.
